## 任务画像

- 任务：1024×1024 三通道遥感影像的二分类水体语义分割。
- 标签：单通道 PNG；`0` 为背景，`255` 为水体。
- 主指标：全测试集像素累计的水体 IoU（不是按图或按 batch 的平均 IoU）。
- 本地数据的编号空位为 346 个，且全部满足 `id % 9 == 8`；它们与 2,768 个训练编号共同覆盖 3,114 个候选编号。该模式可用于本地调试，但不是可见测试标签。
- 用户已有数据报告指出水体像素占比约 1.58%，属于强类别不平衡和小目标场景。

## 已发现的工程状态

`waterseg` 的 v16 路线采用真实正样本 / 纯负样本 / 均匀裁剪、OHEM-BCE、Lovasz、Dice 与边界辅助损失，并把训练划分为 768 裁剪阶段和 1024 全图精调阶段。该工程记录的 v15 线上得分为 0.79257，但这是一条历史记录，尚未在本机重跑或独立验证。

当前 `runs/` 中没有可用 checkpoint；v16 的第二阶段还依赖第一阶段的 `best.pth`。因此不能把 v16 写成“已完成训练”。
