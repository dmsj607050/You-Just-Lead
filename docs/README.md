**约定**：

- 架构类决定写进 `architecture.md`（编号 D1、D2…），不要散落在别处；
- 发布说明里必须留产物摘要 —— 产物不进版本库，能证明它身份的只有摘要；
- 竞争项目的产物（实验、报告、论文）属于工作区，写在 `workspace/<项目 id>/`，
  不写在 `docs/`。
