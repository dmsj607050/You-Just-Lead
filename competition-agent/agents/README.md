# Specialist agents

- `rule_agent.py` — official rules to Markdown and YAML.
- `data_agent.py` — deterministic data audit and reports.
- `literature_agent.py` — paper/repository discovery with provenance.
- `reproduction_agent.py` — approved isolated source reproduction.
- `experiment_agent.py` — baseline and approved experiment preparation.
- `analysis_agent.py` — metrics, curves, and error-sample diagnosis.
- `decision_agent.py` — evidence-backed candidate ranking.
- `paper_agent.py` — evidence-traceable TeX drafting.

Implement these only after their schemas and approval paths are defined.
